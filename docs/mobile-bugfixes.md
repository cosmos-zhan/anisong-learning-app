## 歌词跳转

当前托管对 MP3 Range 请求返回整文件 HTTP 200。旧播放器直接将 HTTP URL 交给 audio，设置 currentTime 后立即播放，未等待 seeked 或核对实际位置；这个实现无法保证在缓存未就绪时完成歌词跳转。

现在 WebAudioEngine 先以同源 fetch 完整读取远程音频，生成本地 Blob URL，再获取真实媒体 metadata 并开放练习。默认约 10.3 MB，首播须等待完整缓冲。歌词选择与循环回跳等待 seeked，并验证实际位置在目标约 80ms 内；拒绝/超时会报 SEEK，不会开始错误位置的播放。暂停、换句、换歌和解码错误取消过期任务；Blob URL 在换歌/销毁时释放。用户本地导入的 Blob URL 不被引擎擅自释放。

此次回归含延迟 seek、静默拒绝 seek、暂停时取消、快速切句、完整缓冲及 URL 回收、UI→真实适配器→异步媒体事件、错误后旧请求不能重启播放。媒体事件替身仍不等于 Android 解码/发声验收。

## 五线谱

旧谱的精细渲染在源码及生产模块的 jsdom 环境可执行，尚未直接复现用户手机的具体异常。因此不能将某个推测原因宣称为已确认根因。已处理可见风险：

- 不再一次生成全谱数万像素宽的 SVG。每次 8 小节，原始小节编号、调号、拍号、谱号和 divisions 继承；当前音符/选中范围可自动换页，可手动前后翻页。单个声部 XML 缓存减少重复解析总谱。
- 隐藏模块停止渲染，旧异步任务取消后不再写入新视图。
- 动态模块/精细排版失败时，用不依赖 Canvas 的 SVG 兼容谱面显示实际解析音符、休止、音名与点击小节。它简化连梁/延音/复杂装饰，页面明确提示，可重试精细谱。兼容谱不是截图，也没有假进度。
- 反馈含 renderer backend 和 SCORE_MODULE/SCORE_LAYOUT 异常类型，不再只显示无法定位的通用提示。
- CI 新增 `node scripts/verify-built-app.mjs`，实际加载 dist 入口和懒加载模块，并等待 SVG 完成；使用 jsdom 与文本宽度替身，明确不是浏览器/手机视觉测试。
