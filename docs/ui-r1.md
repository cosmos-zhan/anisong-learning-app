# App 界面 R1 · 实施与手机验收

本轮按照已确认的 R1 页面设计实施，保留现有真实音频、原轨和弦试听、点句 seek 与谱面兼容修复。主版本 0.3.0。

## 页面与入口

| 页面 | 入口与行为 |
| --- | --- |
| 练习首页 | 默认启动页；继续上次练习、钢琴入口、最近练习。无虚构时长或成绩。 |
| 曲库 | 搜索、全部 / 可学唱 / 可学谱筛选；显示本机资料关联状态。 |
| 歌曲详情 | 同一歌曲下的歌词与钢琴入口、音频 / LRC / 乐谱状态、真实整曲试听。 |
| 添加资料 | 选择已有歌曲或新建歌曲，独立关联音频、LRC 和 MusicXML；谱与歌词不自动同步。 |
| 歌词练习 | 独立深色界面；点击单句 / 反向多句范围、真实进度、暂停、循环、速度和边界抽屉。 |
| 钢琴准备 | 声部、轨道、模式、速度、标记、小节范围。设置不自动发声。 |
| 钢琴练习 | 横屏上谱下琴；默认一组八度（8 白键 / 5 黑键），八度切换，真实按下 / 释放。 |
| 最近练习 | 真实本机歌曲、模块、范围、模式、速度、循环和保存时间。恢复不自动播放。 |
| 设置 / 关于 | 新练习默认速度与音符标记、本机保存说明、真实版本与源码入口。 |
| 反馈 | 从练习的更多菜单打开时先暂停，预览 / 编辑完整报告后复制或打开 GitHub 预填页。 |

底部主导航仅用于浏览页面；完整练习页隐藏。钢琴准备页仍保留主导航。抽屉在竖屏从底部呈现，横屏从右侧呈现，支持 Escape、焦点约束和返回原控件。系统返回通过 URL hash/history 导航并暂停离开的模块。

## 状态与恢复

- `Workspace.tsx` 管理页面和歌曲身份；每首歌曲对应同一组真实播放器，浏览和练习切换不会重新创建引擎。
- `App.tsx` 保留 `LoopController` + WebAudioEngine / Android Media3；新 UI 只调用这些真实接口。
- `PianoWorkspace.tsx` 保留 PianoController、SynthPiano、OSMD / 兼容 SVG。点谱面小节直接试听原轨；范围抽屉应用后需点击播放。
- `packages/core/app-state.ts` 保存偏好、资料摘要、最近练习和 IndexedDB 本机音频 / LRC。乐谱继续使用原有 scoreStore。
- 音频 Blob、LRC 文本与 XML 留在设备。Android 音频保存外部文档 URI，并尽可能保留读取权限；提供方不支持、文件移动或权限撤销时需重选。
- 练习每秒保存；退出 / 打开抽屉时立即保存。保存失败明确提示，播放仍可继续。突然关闭可能损失最近一秒设置。
- 原有 `anisong:songs:v1`、乐谱与琴谱 session 键兼容保留。首次进入自建歌曲不会套用原创示例。合法示例从曲库另行选择。
- `#lyrics` 与 `#piano` 旧深链接继续有效，默认无 hash 打开首页。不同来源（网页、APK）的本机数据独立。

## Android 手机验收顺序

1. 首页 → 曲库 → 春日影。确认资料可见、整曲试听实际发声。首次网页需完整缓冲约 10 MB。
2. 进入歌词学唱：点任一句，听起点是否正确；反向选择多句；打开速度或边界抽屉，应立即暂停；调到 0.5×、微调 ±0.1 秒，再点播放。
3. 返回歌曲 → 钢琴学谱：在准备页改范围 8 到 5、选声部与速度，确认设置时不发声；进入练习并横屏。
4. 点谱面第 5 小节，确认选中原轨真实发声，暂停能停止。通过范围抽屉选择连续多小节，再点播放，确认循环。
5. 启用声音，分别触白键、黑键、双指按住与松开；确认没有松开后持续响的卡音。用八度按钮切换可见音区。
6. 单音轨切等待弹对：错键不推进，正确键才推进。原轨含和弦时明确提示，用户可主动选最高音简化轨，或返回自动试听原轨。自由模式不自动推进。
7. 更多 → 反馈：填写问题，报告应有真实提交 SHA、模式、范围、速度、循环和渲染状态；关闭诊断后删除这些信息。关闭反馈后仍在原练习位置且暂停。
8. 暂停并返回，查看最近练习。刷新 / 重启后恢复设置不自动播放；检查自己导入资料能否恢复。拒绝存储权限时应显示保存失败提示。
9. 添加资料 → 新建歌曲：先 LRC，后音频，再导入 MusicXML。确认关联到新歌曲，未套用春日影或原创示例。测试无效 XML，旧谱应保留。
10. 测试系统返回、旋转、切后台、蓝牙 / 来电后回到界面；应暂停，再次点播放 / 启用声音继续。

## 本轮实际验证与限制

- `npm run check`：严格类型、ESLint、17 文件 / 124 测试、production build 通过。
- 新增 8 个交互 / 恢复用例，覆盖统一导航、新建歌曲、无假谱、歌词真实控制器跳转、抽屉暂停、范围反选、13 键、反馈、LRC 先导入及保存失败。
- `scripts/verify-built-app.mjs` 执行构建后的实际 ESM、懒加载渲染器与谱面点击；8 小节 SVG、真实 SynthPiano 节点调度、暂停、反馈快照、退出、首页和曲库导航通过；兼容 SVG 路径另由渲染回归用例覆盖。Web Audio 节点在 jsdom 边界做仪器化，不能证明实际扬声器发声。
- 当前环境无可用浏览器控制技能或 Android 真机，因此未声明手机视觉、触控、Media3 听音与音高验收通过。
- 全部未支持的旧边界继续存在：不自动对齐 MP3 与总谱，不做多声部合奏 / 和弦判分，网页循环可能有短暂间隙，锁屏后台不播放。低高度分屏可能需要横向滚动控制条或谱面。
- 浏览器可回收站点存储，APK 卸载会删除本机资料；保留导入文件。debug 签名为构建环境生成，若旧版签名不同，需先备份本地原始文件再卸载旧版。
