# UI R1 第一批：钢琴练习与抽屉返回

版本 0.3.1。以 R1 差异审查中的钢琴主界面、小节选择、速度抽屉与返回行为为本批范围。首页、曲库、学唱布局、反馈两步预览、钢琴模式 / 声部 / 标记的独立面板留到后续批次。

## 本批变化

- 钢琴主界面恢复紧凑控制带：小节范围、重练、圆形播放 / 暂停、速度、循环、音符标记、低 / 高八度。八度和声音不再占用独立工具行；提交 SHA 移出钢琴工作台，仍可在关于与反馈中查看。
- 声音未启用 / 中断时在顶部提供启用入口；琴键仍为一组八度、真实按下 / 释放、多点触控。播放与目标音来自原有控制器状态和音频时钟。
- 小节抽屉改为点选网格，每组最多16小节：点起点 → 点终点 → 预览 → 确认。支持反选、跨组、同一小节连续点两次选择单小节。确认前不修改控制器；关闭 / 返回取消草稿；应用后保持暂停，由用户点播放。
- 速度入口只打开0.5 / 0.75 / 1 / 1.25倍四项，不再先进入整个参数表。当前选中值明确标记，范围不变。
- 抽屉竖屏贴底、横屏贴右。小节网格内部滚动，预览与确认按钮留在面板中，不随140小节的内容被推到很远的位置。
- 每次打开抽屉增加同地址的临时历史项。浏览器返回先消费该项并关闭面板；显式关闭、Escape、遮罩关闭也消费该项。菜单跳转等待面板关闭后才改变页面，避免重复返回与旧抽屉遗留。
- Android `MainActivity` 使用 AndroidX 返回调度，将有网页历史时的系统返回交给 WebView；无历史时保留系统默认退出 / 返回行为。实际手势仍待 Android16 真机验收。

## 布局约束核对

旧布局在844×390且安全区额外值为0时，固定 / 最小行高下限约406.6px。本批改成五行：44px标题、可收缩谱面、44px控制、24px状态、可收缩键盘，行间距4px。等待休止的“下一步”状态行使用44px。谱与键盘分享剩余高度，内容在各自区域滚动，不用固定最小行高撑出全屏容器。

| 可用视口 | 上下padding合计 | 状态行 | 谱 / 键盘各分配 | 固定行超出 |
| --- | --- | --- | --- | --- |
| 844×390 | 8px | 24px | 127px | 0 |
| 800×360 | 8px | 24px | 112px | 0 |
| 740×320 | 8px | 24px | 92px | 0 |
| 740×320 | 48px | 24px | 72px | 0 |
| 844×390 | 8px | 44px | 117px | 0 |

这是CSS约束计算，不是浏览器截图、字体排版或触控验收。真实总谱的垂直 / 水平滚动继续保留；窄屏控制带可横向滚动。

## 自动验证

新增 `tests/piano-refinement.test.tsx`：

1. 播放时打开范围暂停；反选预览；确认才提交；取消保留原范围；应用后仍可真实调用控制器播放。
2. 速度面板只有四项速度，无声部 / 轨道大表单；改速后范围不变且暂停。
3. 16小节分组之间选择连续范围；同小节两次点选。
4. 第一次浏览器返回关面板，第二次回准备页，重进不残留旧面板。
5. 显式关面板后，下一次返回直接到准备页，没有多余历史停留。
6. 更多菜单跳转前先消费面板历史。

原有歌词seek、原轨和弦试听、MusicXML解析、谱面兼容、实际合成器节点调度等回归继续执行。构建后DOM校验将谱面SVG与新图标SVG分开，避免把图标误当成五线谱已生成。

本地 `npm run check` 已通过：18个文件、130项前端测试、类型检查、Lint与production构建。Android已完成debug构建与5项原生单元测试；构建后ESM的DOM检查也已通过：真实谱面SVG、8个可点击小节、触发合成器9个振荡器节点、暂停、反馈快照、范围网格、独立速度面板、抽屉返回与退出导航。此检查使用jsdom与仪器化Web Audio节点，不等同于听音或真机浏览器验证。

## 手机验收

1. 进入春日影 → 钢琴准备 → 进入练习，横屏。检查谱、控制带、完整白 / 黑键同时可见；尤其检查浏览器地址栏占空间时的短横屏。
2. 直接点谱面小节，应从该小节试听；播放 / 暂停和重练保持实际音频行为。
3. 打开范围，先8再5，预览5–8；未确认前范围不变。确认后手动点播放。再改一个未完成的起点并返回，原5–8范围应保留。
4. 选择器跨组选择，例如8–20，确认后循环；用同小节两次点选选单小节。
5. 点速度，只看到四档；选0.5，关面板后保留范围。再次按返回，应回准备页。
6. 在任意抽屉中按浏览器 / Android系统返回：先关抽屉且留在练习，再返回才离开练习；重新进入不应出现旧抽屉。
7. 启用声音，多指按黑 / 白键并释放，切八度，测试旋转与后台暂停。反馈附实际版本与当前状态。

## 验收边界与恢复

当前环境没有可用浏览器控制技能和物理Android，未声明设计像素对齐、系统返回手势、音高听感或多点触控通过真机验收。第一批不代表30项设计差异全部关闭。

后续Work克隆仓库并切 `feature/piano-p0`，执行 `npm ci`、`npm run check`、`node scripts/verify-built-app.mjs`。Android使用JDK21 / SDK36，先`npx cap sync android`，再运行原生单元测试和debug构建。复用现有部署身份，私有录音、LRC和总谱继续放在忽略的private-media目录，不提交到公开仓库。
