# Android 手机测试指南

## 浏览器验收（先进行）

1. 使用最新 Chrome 打开交付中的实际网页 URL；当前 Sites 备选网页是私有的，需要登录创建它的 ChatGPT 账号。
2. 首页显示版本 SHA、分支、构建时间。演示先加载但不自动发声，点「播放」才试听。
3. 默认第 2 乐句起点 16.30、终点 21.10，速度 0.75×。听数轮，理论每轮 6.4 秒；解码 / seek 延迟可使实测略长。
4. 点第 3 行立即从第 3 乐句开始。暂停后数秒再播放，观察从暂停位置继续。
5. 选「多句连续」→第 2 句→第 4 句，范围应为 16.30–30.70；反向点第 4→第 2 范围相同。第一点后应暂停；取消起点不会播放。
6. 切 0.5× / 0.75× / 1×，确认音高大致保持，UI 仍显示原曲秒数。切换循环为关闭，应在当前片段结束时停止。
7. 展开微调，将起点延后 0.1，应显示16.40，并从新起点练习。非法超短范围应有提示。拖进度条不能越出选中范围。
8. 导入本地 MP3/M4A/WAV，再导入匹配 LRC；歌曲与歌词不上传。测试无时间戳、乱序、重复时间、最后行、越界行，应得到提示。
9. 快速点不同歌词 / 连点播放 / 回跳附近暂停，确认不再被旧操作重新启动。
10. 切到别的应用再回来，应保持暂停，手动恢复。刷新后本地歌曲须重新选择；演示仍可重新载入。
11. 点「反馈问题」，填写描述和步骤，检查行号、速度、时间与版本准确；移除诊断后复制，或打开 GitHub 预填草稿确认提交。

演示是器乐，不包含日文演唱。日文文本用来保留任务书的界面例子；真实歌词对齐请使用自己的合法歌曲与 LRC。

## Android APK

包含原生代码变更的PR会自动生成APK；可以在该PR的Checks中进入Android debug APK运行下载。仓库合并main后也可手动构建：仓库→Actions→Android debug APK→Run workflow→选择 main→Run。完成后打开这次 run，在 Artifacts 下载 `anisong-debug-<SHA>` ZIP，手机文件管理器解压并点 app-debug.apk 安装。Artifact 一般需登录 GitHub，30 天后过期；这是测试签名。不同云环境生成 debug keystore 时可能不一致，若无法覆盖安装可卸载旧测试版再装（P0 不保存练习数据）。

如果交付提供直接 APK 文件，下载该文件也可安装。Android 提示时为正在使用的浏览器 / 文件管理器开启「允许安装未知应用」，安装后可关闭。

包名 `io.github.cosmoszhan.anisong`，versionName 0.1.0，默认 versionCode 1；CI 使用 run_number。Android 16 目标 SDK36。打开 App 后重复以上操作，特别检查系统文件选择器、含空格/中文名文件、SD卡/网盘提供方、蓝牙耳机、来电和后台切换。

## 反馈格式

填写「版本 + 操作 + 预期 + 实际」。例如：0.75× 第2句，到第二轮结尾点暂停，约1秒后又播放。截图可录到范围、速度、版本。测停顿时说明设备与音频格式，不将理论每轮时长当成精度实测值。
