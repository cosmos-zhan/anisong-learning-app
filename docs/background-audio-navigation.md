# 0.3.7 后台播放、导航与钢琴音频修复

## 行为

- Android 学唱与钢琴自动试听使用 Media3 `MediaSessionService`。播放器由 Service 持有，Activity 暂停不再暂停音频；系统媒体通知提供播放 / 暂停。耳机拔出、音频焦点丢失仍暂停。系统强制停止 App 不保证恢复。
- 钢琴自动试听把当前声部、范围和速度映射为真实音符音频，在工作线程分块生成单声道 PCM WAV，交给同一个原生媒体服务循环。实际原生播放位置反算谱面 tick，切后台无需 WebView 计时器。首次准备会显示生成提示；取消、换范围、切歌曲会取消旧任务。范围最多30分钟 / 20,000音符，超限报错。
- 等待弹对和自由弹奏仍使用实时 Web Audio，切后台释放触键并暂停交互。旋转、离开练习页面仍暂停；返回手机桌面与 App 内导航是不同事件。
- 网页学唱移除主动后台暂停，加入系统媒体播放 / 暂停操作及 timeupdate 边界检查。浏览器可冻结网页和限流计时器，因此网页后台的片段循环不能承诺与 Android 服务一样连续；钢琴网页交互在后台仍暂停。
- 所有普通页面共享顶部栏、固定左上返回按钮和底部导航，中间内容独立滚动。学唱 / 钢琴练习保留固定的深色专注顶栏。
- 合成器降低音量，增加输出软限幅、8ms起音与80ms释放、正确保持音量包络、取消尚未开始的音符、全部振荡器结束后断开节点、过滤超过 Nyquist 的泛音。密集和弦与短促松键不再直接满幅叠加。不把这些代码检查等同于已经复现 / 消除用户耳机上的所有杂音。

## 验证入口

- `npm run check`：前端状态 / 解析 / 交互、音频调度、原生试听位置与取消竞态、隐藏页面学唱持续播放、发布规则。
- `npm run test:browser`：原有10组钢琴比例、同会话旋转 / 真实触键；新增4种比例 × 8普通页面的真实滚动固定导航检查与截图。用实际合成器代码在 Chromium OfflineAudioContext 渲染单音、32音叠加及取消未来音符，测量真实 PCM 峰值、均方根与尾音。
- `npm run android:check`：以上核心检查、真实产物交互检查、Capacitor sync、clean、Kotlin 单测与 APK。新增 `PianoPcmTest` 检查实际 WAV 字节、非静音、64音叠加峰值、平滑端点、取消及输入限制。

浏览器结果保存在 Actions 的 `piano-browser-screenshots` 附件中；原生结果与签名 / 安装版本在 APK Release 的 `build-info.json` 中。最终运行结果及提交见交付记录，不在未执行前宣称通过。

## Android 手机验收

1. 安装此版本，选择原创示例，学唱点选第二句。按 Home 返回桌面，等待至少30秒，再锁屏30秒。确认仍循环该句；通知栏暂停 / 继续应生效，返回页面位置和播放状态一致。
2. 钢琴自动试听选连续2–4小节，确认发声后按 Home / 锁屏，等待两轮；返回后小节高亮应对应当前播放。再关闭循环检查范围结束停止。
3. 试听准备期间立即返回、切声部或切歌曲，确认旧音符不会随后响起。等待弹对、自由弹奏后台应暂停；前台触键恢复后没有卡住的持续音。
4. 用较低系统音量比较单音、快速反复点同键和密集和弦；若仍有爆音，在反馈中写明模式、声部、小节、速度、耳机连接方式与复现操作。自动 PCM 测量不能覆盖具体耳机 / 蓝牙 / 系统混音链路。
5. 320×640、393×873、740×320、960×432分别覆盖窄屏、长屏、短横屏和宽横屏；每页滚动到底，返回键留在左上，底栏不遮挡最后内容。

尚未完成物理 Android16、锁屏 / 厂商省电、蓝牙耳机和真实听感验收。请不要把 CI 构建成功解释为这些场景已经验收。

## 0.3.8 收尾（2026-10-21）

继续复查发现：原生试听生成期间原先标记为“暂停”，主按钮实际会再次生成而不能直接取消。现增加独立 `preparing` 状态，显示准备提示，并提供“取消试听准备”按钮；切换范围、暂停或离开后，晚到的生成完成不会恢复播放。旧播放器暂停 / 位置事件不能覆盖准备状态，通知栏暂停也不会被异步回执撤销。生成过程中调整的循环开关会在音频就绪后重新应用。

歌曲详情试听按钮与进度条统一为绿色，导入按钮去除旧版蓝色边框。浏览器回归增加真实 computed style 检查；控制器与界面回归覆盖生成期间直接取消、通知栏暂停、准备期间循环变化。新版本仍必须完整构建 APK 后发布，不能复用0.3.7产物。

Cloudflare 再次实际检查仍为登录页；安全授权尚未确认。此前构建均已完成，没有后台构建停滞。账号授权完成前仅维护同一个私有试用站，不把工程配置标记为 Pages 部署成功。
