# UI R1 学唱页：歌词与底部播放器

版本 0.3.3，接续钢琴两批改进，依据已确认 R1 的歌词专注页、多句选择、微调和速度场景实施。本批只调整学唱练习与相关面板，仍共享原有歌曲、媒体和反馈基础设施。

## 与设计稿对应的变化

| 区域 | 当前实现 |
| --- | --- |
| 标题 | 春日影与 CRYCHIC ver. / 歌词学唱分层；统一 SVG 返回和更多图标。自建歌曲仍使用其真实名称。 |
| 选择模式 | 单句、多句与当前第几句摘要同排；移除额外的“选择练习片段”标题行。模式按钮的可视胶囊约34px，触控高度44px。 |
| 歌词 | 每行只有序号和歌词，移除逐行时间戳及装饰符号；16px字体、约58px最小行高，选中整行用浅一层的绿色。长句按实际文字换行，列表独立滚动。 |
| 播放器 | 深绿底部面板，64px圆形播放键；上一句 / 下一句与速度、循环、微调三等分入口。完整边界仍使用原曲秒数，进度下方显示片段内已播放 / 总长。 |
| 配色 | 主背景 #142923、选区 #294B3C、底部 #1C342A、进度 #D9B18B，与 R1 对应；没有绘制假的系统状态栏或固定时间。 |
| 速度 | 独立浅色三档面板；打开先暂停，变速保留片段边界，关闭后不自动播放。 |
| 微调 | 起点 / 终点先在面板内预览；关闭或返回丢弃草稿，点击“应用并返回”才一次提交两端并定位新起点。保留原 LRC 的毫秒精度，每次增减0.1秒。 |

准备与播放状态来自实际控制器。选句仍等待真实媒体 seek 完成后播放；不是动画计时。片段进度的可视时间为原曲坐标减起点，滑块 min/max/value 与引擎继续使用原曲秒数。0.75倍时显示的是片段原曲时间，不是额外伪造的墙钟耗时。

常规导入 / 保存提示收到可展开的状态区域；实际错误、读取失败、存储失败等仍直接显示。横屏将歌词与播放面板分为左右两区，短竖屏缩小控件间距；歌词与面板内消息可各自滚动。

## 实现与验证

- `LyricsPractice.tsx` 为学唱专注页，回调接原有 LoopController；旧资料页与整曲预览继续使用原播放器。
- `TrimRange.tsx` 管理可取消草稿；`LoopController.applyRange` 校验两端、一次设置范围、等待 seek，并始终保持暂停。旧微调接口仍兼容旧界面。
- 异步操作有序号保护；已关闭微调的旧请求不会关闭新打开的速度面板，也不能重新播放或覆盖新选句。
- 自动测试覆盖相对显示与原曲 seek、点击与反向多句、速度保留范围、微调取消 / 确认 / 保存、失败重试和异步取消；原有真实 WebAudioEngine 媒体事件回归用于新版页面。
- 本地 `npm run check` 已通过：19个测试文件、144项测试、类型检查、Lint与 production build。
- 生产ESM检查验证私有构建42句歌词、实际适配器 seek→play 调用、相对进度、微调预览隔离、确认后暂停、反馈范围，以及钢琴回归。该检查使用 jsdom 和仪器化媒体事件，不证明浏览器画面、真实解码或听感。
- Web CI新增 `node scripts/verify-lyrics-build.mjs`，在普通公开CI中使用合法示例；私有发布仍校验内置媒体齐备。

## 手机复测

1. 打开现有测试站的春日影歌词学唱页。应看到短歌名、版本副标题、单句 / 多句与范围同排；歌词行不再附时间戳。底部为圆形播放键及三项参数入口。
2. 点第2句，确认从该句实际开唱；原曲边界应为19.371–25.586秒（可视四舍五入为19.37–25.59），片段进度从0开始。
3. 多句先点第4句、再点第2句。点起点后暂停，选终点后按2–4句实际循环；点暂停确实停声。
4. 点微调，起点加0.1，再返回取消，原范围不变；重新打开，草稿应恢复原值。再次微调并应用，返回后保持暂停，主动播放从新起点开始。
5. 打开速度选0.5倍，关闭后范围不变；速度、循环与微调无需在长表单中寻找。循环关闭后应在片段末停止。
6. 在360×640左右的短竖屏、普通竖屏及横屏检查歌词和播放按钮；长句换行后仍可滚动；底部系统导航区不遮挡参数按钮。
7. 反馈确认真实版本、选句、速度、循环与应用后的原曲边界。测试返回先关抽屉，再离开页面；离开后暂停。

## 验收边界

当前没有可用浏览器控制技能或物理 Android，已检查原设计的图像和源码布局，但尚未完成实际浏览器截图并排、手机字体、安全区、触控和听音验收。因此不把这次交付称为像素级还原。字体保留系统 CJK 回退，不加载第三方远程字体；不同手机字形可能略有差异。

本次优先交付相同网址的网页更新，手机无需重装即可比较。GitHub Actions仍会构建Android源码测试包；公开CI包不包含用户的私有歌曲。签名与安装说明沿用已知问题记录，未宣称执行本轮Android真机安装验收。
