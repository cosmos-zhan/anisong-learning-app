# 钢琴：Android 16 手机验收

[打开现有固定测试站的钢琴入口](https://anisong-learning-lab.woolly-mochi-2205.chatgpt.site/#piano)。保持原站的私有访问范围，使用同一 ChatGPT 账号登录。Chrome 手机浏览器建议更新到可用稳定版；关闭系统静音/蓝牙路由疑问后再试听。浏览器限制下不能保证强制横屏，手动旋转手机即可。无需电脑、无需安装 APK。

本表是**验收步骤**，不是已完成的真机记录。本次开发环境没有实体 Android 或可用浏览器控制，自动化通过不等于下表通过。

1. 刷新页面，核对底部 SHA 与 [PR #3 提交](https://github.com/cosmos-zhan/anisong-learning-app/pull/3/commits)。切到“钢琴学谱”，默认显示“晨光练习曲 · 原创八小节”。点“启用声音”，再点 C4、黑键 C♯/D♭4，应该真实发声，松开释放。若提示音频中断，重新点启用声音；不得把静音情况当作成功。
2. 手机横屏。上方真实五线谱、中间控件、下方琴键应同时可见。谱面可左右滚动；很矮的窗口可能需在谱面区上下滚动，控件和琴键应留在视口内。旋转会暂停；再点播放继续，检查无挂音、无双重播放。
3. 点第 5 小节按钮或谱面：只选第 5 小节并试听。点“选择范围”，再点 5、8：应包括 5–8；再试 8、5，范围相同。选区淡色与当前绿色音符不同。循环回到第 5 小节，关闭循环后在第 8 小节末停止。试前后小节、暂停/继续和重练。
4. 选第 2 小节检验附点与休止；第 3 小节含 F♯4，可检验黑键。切 0.5× / 0.75× / 1× / 1.25×：范围保持原小节，音高保持，节奏变慢/变快；指针应跟随听到的音，反馈明显错位。
5. 选第 5 小节，切“等待弹对”，点“开始等待”。目标从 C4 开始；弹 C♯4 不推进，弹 C4 才到 E4。按住同键不应继续推进。休止需点“下一步（休止）”，不会假装在跟拍。连续完成后按循环开关回到起点或停止。暂停时触键只发声，不推进。
6. 切“自由弹奏”，同时按 C4 与 E4，再分别松开；再试一黑一白、快速连击。五线谱不自动前进，无强制评分。按住时切模式、换范围、旋转、切后台、锁屏、返回，不能残留旧音符；回来后需主动播放。
7. 点击“谱面设置”，切音名/固定唱名/关闭，检查符号在音符附近，不遮掉必要升降号。固定 Do 是 C，不是调内主音。“谱面设置→练习声部/旋律轨道”显示当前目标。
8. 下载或准备自己有权使用的至少 8 小节、3/4 或 4/4、单声部 MusicXML，点“导入乐谱”。可从本站 [合法示例 XML](https://anisong-learning-lab.woolly-mochi-2205.chatgpt.site/demo/piano-demo.musicxml) 下载后重新导入。检查名称、拍号、调号、速度与小节数量。再用制谱软件导出的 MXL 重复。试多乐器/voice 文件，切换后仅当前轨道发声（自动试听包括该轨和弦），原谱其他声部保留。
9. 导入错误 XML / 损坏 MXL：应说明原因，旧谱仍在。含普通和弦/重叠的当前轨道应可自动试听；等待弹对应提示单音限制，可选最高音练习或切回自动试听。移调/微分音等不支持轨道仍应明确拒绝。含反复谱应先确认“按书写顺序”，不把反复展开能力当作已实现。
10. 选择 5–8，0.75×，等待模式，唱名开启，完成数音，切后台再返回，刷新。应恢复原谱、范围、设置与位置，且**不会自动播放**。同歌曲下可在已保存乐谱列表换谱。隐私模式/禁用存储时应看到保存失败提示，保留源文件。
11. 点“反馈”，核对真实版本、当前小节、模式、速度。报告不应自动含曲名、文件名或原谱。可编辑、取消诊断、复制；GitHub Issue 打开后由你提交。截图在 GitHub 加入，别附未经授权的谱文件。
12. 返回歌词学唱，验证原来的音频/LRC 导入、单句与多句循环仍正常；钢琴声音此时已停止。再回钢琴保留当前谱和范围。

## 默认总谱选小节复测

选择春日影总谱，谱面设置确认钢琴 P2、谱表1/声部1、原轨；切“自动试听”，点击第1小节，应出现暂停按钮并听到该轨音符，无需先切最高音。选择范围按8→5，应试听并循环5–8。暂停后重练，切0.75×，确认节奏改变但音高不变。切等待弹对，含和弦轨应说明单音限制，按钮可切回原轨试听。此条仍等待物理 Android 验收。
