- 顶部“官方试听（片段）”：用户点击后才加载标准 YouTube 嵌入播放器，来源为 `wRwQUk0Dl30`，标题“春日影（アニメ「BanG Dream! It's MyGO!!!!!」#3 挿入歌）”，发布者“バンドリちゃんねる☆ / @bang_dream_official”。2026-10-17 用官方 YouTube oEmbed 核对标题和发布者。参考链接：https://www.youtube.com/watch?v=wRwQUk0Dl30 。该参考为动画第 3 话的 CRYCHIC 片段，不是完整音源或 THE FIRST TAKE 版。
- 用户打开官方试听时先暂停本地练习；关窗、切学习模块、切后台会移除外部播放器。若地区或嵌入限制导致不能播放，可使用“打开官方视频”链接。网页不下载或缓存该录音。
- 点“启用声音”可以自由试琴。尚无结构化乐谱时，不显示虚假的小节或音符，也不启用自动试听/等待判定。
- 钢琴页“导入乐谱”接受自己的 MusicXML / XML / MXL；导入后才显示实际谱面、声部、小节范围、试听与等待弹对。实际文件保存在该歌曲身份下，刷新能恢复。原谱内容来自导入文件，不自动声称已核对编曲版本。
- 歌词页默认自动加载用户提供的 MP3，原速 1×，等待点击后真实播放；支持暂停/继续、拖动进度、变速与整曲循环。不依赖 LRC 才能播放。导入与该录音时轴匹配的 LRC 后可逐句循环，也可返回整曲试听。无 LRC 时不虚构歌词，上一句/下一句禁用。
