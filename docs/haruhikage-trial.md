# 春日影（CRYCHIC ver.）试用入口

本轮按用户要求把默认歌曲改为《春日影（CRYCHIC ver.）》。[直接进入钢琴页](https://anisong-learning-lab.woolly-mochi-2205.chatgpt.site/?song=haruhikage-crychic#piano)。原来的 CC0 原创音频和八小节谱保留在“原创示例 / 原创演示”，不混作这首歌的内容。

## 当前可以试用的部分

- 顶部“官方试听（片段）”：用户点击后才加载标准 YouTube 嵌入播放器，来源为 `wRwQUk0Dl30`，标题“春日影（アニメ「BanG Dream! It's MyGO!!!!!」#3 挿入歌）”，发布者“バンドリちゃんねる☆ / @bang_dream_official”。2026-10-17 用官方 YouTube oEmbed 核对标题和发布者。参考链接：https://www.youtube.com/watch?v=wRwQUk0Dl30 。该参考为动画第 3 话的 CRYCHIC 片段，不是完整音源或 THE FIRST TAKE 版。
- 用户打开官方试听时先暂停本地练习；关窗、切学习模块、切后台会移除外部播放器。若地区或嵌入限制导致不能播放，可使用“打开官方视频”链接。网页不下载或缓存该录音。
- 点“启用声音”可以自由试琴。尚无结构化乐谱时，不显示虚假的小节或音符，也不启用自动试听/等待判定。
- 钢琴页“导入乐谱”接受自己的 MusicXML / XML / MXL；导入后才显示实际谱面、声部、小节范围、试听与等待弹对。实际文件保存在该歌曲身份下，刷新能恢复。原谱内容来自导入文件，不自动声称已核对编曲版本。
- 歌词页默认同一首歌；需导入 CRYCHIC 音频及与该录音时轴匹配的 LRC，之后可逐句循环。默认不自动装入原创器乐或歌词示例。

## 当前缺少的素材与验收

当前未收到《春日影》的录音、LRC 或 MusicXML/MXL，没有把商业录音、完整歌词或第三方乐谱放进公开 GitHub。当前是“默认歌曲 + 官方参考 + 本地导入”的入口，**还不是已内置《春日影》乐谱的完整钢琴练习示例**。可直接在手机页面选文件导入；若需要 Work 配置实际曲谱，须提供相应 MusicXML/MXL 文件。PDF、图片不能直接用于当前学谱模块。

官方嵌入播放器不参与本地 LRC 片段循环、钢琴音符调度或自动同步。没有伪造歌曲演奏、音符或已通过的手机听感验收。

## 默认及数据策略

歌曲 ID `haruhikage-crychic`。新用户默认此曲；旧内置示例默认只迁移一次，原歌曲和谱的关联保留。已有个人导入歌曲继续保留，点击顶部“春日影”或上述专用链接可切回。主动选择“原创示例”时使用独立 `demo-original` 身份。
