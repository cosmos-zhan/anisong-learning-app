# 手机素材包：无需在云浏览器登录 Cloudflare

0.5.0已按用户澄清提供 [App内下载管理](download-manager.md)作为主流程；本文素材包位于“下载管理 → 本地导入与存储”，仅作为已有本地文件的补充导入方式。

从0.4.2开始，App可一次导入 `.anisong.zip`：同一首歌的音频、LRC歌词和MusicXML/MXL乐谱一起校验、保存。包内所有文件通过后才写入原有IndexedDB事务；损坏、取消或空间不足不替换原资料。练习设置继续使用原来的歌曲ID。导入过程不联网、不上传文件。

## 手机使用

1. 手机浏览器打开现有[私人测试站](https://anisong-learning-lab.woolly-mochi-2205.chatgpt.site)，使用所有者账号访问。
2. 曲库 → 在线素材 → **下载春日影素材包**，保存到手机“下载”目录。也可使用所有者私有文件中提供的同格式素材包。
3. 打开App或同域网页，曲库 → 在线素材 → **选择素材包导入**，选择该 `.anisong.zip`。不用解压，也不用输入Cloudflare账号、API Token或素材源访问码。
4. 看到“素材包已导入并保存”后，在本地下载列表点击歌曲，进入学唱或钢琴练习。
5. 导入完成后，Android可断网重开App；网页刷新仍需取得网页程序，但不再请求音频/歌词/乐谱服务。

网站负责让所有者在自己的手机浏览器下载文件，App只读取手机选中的文件，因此不需要在Work的云浏览器登录第三方账号。保留原有私有站访问范围，不新增公开素材服务。原来的目录URL下载继续保留，独立Cloudflare Worker改为可选的后续部署方式。

## 包格式

ZIP根目录包含 `catalog.json` 与它引用的单曲文件，沿用 [素材目录schema 1](media-downloads.md)。当前每包仅一首歌，必需音频，可选LRC和乐谱。包内URL必须是根目录文件名，不能引用网络、文件夹或外部路径；不含账号、访问码、部署代码或签名密钥。

压缩包上限36 MiB，展开上限35 MiB，最多4个文件（含目录）；目录512 KiB、音频30 MiB、LRC128 KiB、乐谱4 MiB。路径、重复条目、多曲、额外文件及大小/哈希不符均拒绝。普通ZIP、先前的Cloudflare部署ZIP和签名备份不是素材包，不能导入。

私人构建的 `scripts/bundled-audio.mjs` 从原始私有输入自动生成素材包与校验值，保存到被忽略的 `public/private-media/`。不在公开仓库或公开APK中生成私人包。公开产物检查同时拒绝非空 `mediaConfig.package` 与APK中的私人目录。

## 验证与边界

核心测试验证无网络导入、三类资料及元数据、损坏保护、路径/远程引用限制、展开大小和取消。真实Chromium回归在393×873和740×320使用实际CC0音频/歌词/乐谱ZIP，经文件选择入口先导入损坏包再导入完整包；阻断素材服务后刷新，验证真实本地音频时钟推进与谱面恢复。私人包发布前另核对实际文件字节数、SHA256和目录内容。

物理Android16文件选择器、浏览器实际下载提示、离线重启和覆盖安装仍需手机验收。WebCrypto要求HTTPS（Android使用https://localhost）；素材包没有改变程序离线壳和固定签名的限制。APK同签名覆盖更新保留资料，卸载或清除App数据会删除资料；尚未配置固定签名时不能保证跨CI构建覆盖安装。素材包是可保留并重新导入的原文件，不等于练习进度备份。
