# 在线素材与本地下载

当前主流程是 [App内下载管理](download-manager.md)：自动读取在线列表、点击下载、任务队列和本地管理。0.6.1 默认春日影无需访问码。新增在线歌曲的操作见 [新增歌曲](adding-songs.md)，下文为通用目录格式。[单曲素材包](media-packages.md)保留为补充导入入口。

曲库 → 下载管理 → 在线歌曲 → 下载到本地。音频、LRC 与乐谱先下载、核对字节数和 SHA-256，再解析文本和乐谱；全部成功后在一个 IndexedDB 事务内保存。失败、超时或取消不会覆盖现有资料。只有目录本次提供的文件被替换，未提供的本地资料保留。

下载完成后可以进入原有学唱、钢琴练习；本地文件优先于内置示例。下载记录和歌曲元数据一起保存在 IndexedDB，localStorage 曲库索引缺失时仍可恢复到曲库。App 更新不把素材写进安装包，也不重置资料库。

## 一份目录就是一个素材服务

最小服务只有 `catalog.json` 和它引用的文件。无需上传接口、数据库、搜索服务或音乐平台账号。可部署到已有 HTTPS 静态托管、对象存储或自己的文件服务器。GitHub 公开仓库只放源码、目录元数据和原创示例；默认春日影文件由独立服务按所有者授权公开读取。其他私人素材可用自定义受限源。

```json
{
  "schema": 1,
  "title": "我的练习素材",
  "songs": [{
    "id": "my-practice-song",
    "title": "我的歌曲",
    "revision": "1",
    "audio": { "url": "audio.mp3", "name": "audio.mp3", "bytes": 12345, "sha256": "文件真实的64位十六进制SHA256" },
    "lyrics": { "url": "lyrics.lrc", "name": "lyrics.lrc", "bytes": 123, "sha256": "文件真实的64位十六进制SHA256" },
    "score": { "url": "score.mxl", "name": "score.mxl", "bytes": 1234, "sha256": "文件真实的64位十六进制SHA256" }
  }]
}
```

此例仅说明字段，大小和校验必须使用真实文件值。audio 必须有；lyrics、score 可省略。URL 可以相对目录，也可为 HTTPS 文件直链。单曲音频上限30 MiB、LRC 128 KiB、乐谱4 MiB；目录最多100曲、512 KiB。下载不执行目录中的代码，不支持 HTML 分享页、用户名/密码 URL 或任意本机路径。

源码包含完整可下载的 CC0 源 `public/demo/catalog.json`，可用“试用原创示例源”实际验证。普通 HTTPS 构建可通过该站点的 `demo/catalog.json` 提供示例服务；它不含私人录音。私有测试站可用“下载本站私人练习素材”，沿用该站点现有访问范围。

### 从文件生成素材源

准备一个只在私人工作目录中使用的配置（不要提交私人文件路径或内容）：

```json
{"title":"我的素材","songs":[{"id":"my-song","title":"我的歌曲","revision":"1","audio":"/path/to/song.mp3","lyrics":"/path/to/song.lrc","score":"/path/to/score.mxl"}]}
```

运行 `node scripts/create-media-catalog.mjs SOURCE.json OUTPUT_DIRECTORY`。脚本复制文件、计算校验值并生成目录；不会自动提交或上传。上传整个输出目录到自己的 HTTPS 服务后，将服务器实际提供的 catalog.json 地址填入 App。以后增加歌曲或改素材版本，只需更新源；App 用户主动重新下载，不会因检查更新而覆盖本地编辑。当前默认服务使用管理员上传接口，需合并线上已有歌曲并最后上传完整目录，详见 [新增歌曲](adding-songs.md)，不要直接拿单曲目录覆盖线上目录。

## 私人源访问与跨域

同域网页可以使用现有登录 Cookie。跨域素材源必须允许实际 App 网页 Origin 和 Android WebView Origin（默认 https://localhost）的 CORS GET；如使用公开匿名示例，也可 `Access-Control-Allow-Origin: *`。先正确配置服务器，App 不绕过浏览器访问控制。

跨域请求不携带 Cookie。0.4.1支持私人素材源专用访问码：只在当前页面内存保留，仅向用户选择的目录Origin附加Authorization，带码请求不跟随重定向，不向目录引用的其他域名转发。访问码不进入反馈或下载记录。私人源也可以使用服务端生成的短期签名文件地址。Cloudflare Access 登录网页或网盘分享页不等同于可供Android直接下载的文件接口。无需R2的受限Worker实现与账号授权边界见 [私人素材服务](private-media-service.md)。

默认源匿名读取；上述访问码机制仅适用于用户自定义的其他私人源。素材地址仅保存在当前设备供下次使用，不附到诊断报告。目录与文件的 SHA-256 用于检测下载错误，不代替访问授权。

## 本地保存与更新边界

- 网页使用当前 Origin 的 IndexedDB。正常部署新程序不会清空；更换域名、浏览器、无痕模式、用户清除站点数据会影响可用性。可点“申请持久存储保护”，浏览器是否授予由浏览器决定；不能承诺永不清理。
- Android 下载素材也保存在 WebView 的本地资料库。实际播放时将已验证的音频复制到 `filesDir/downloaded-audio`，通过只允许 SHA-256 的令牌交给 Media3，不依赖临时 Blob URL 或网络。
- Android 需要同包名、同签名且递增 versionCode 才能无损覆盖安装。当前已配置固定签名，但历史 0.4.2 / 0.5.0 临时签名包无法凭当前固定密钥覆盖（见 android-previews.md）；不要通过卸载旧版完成更新后还期待旧数据保留。
- 卸载 App、清除 App 数据会删除资料。当前不提供跨设备同步或素材导出备份。
- 素材离线与网页程序离线是两件事：已打开的网页可离线练习，离线重新打开网页仍依赖浏览器缓存，当前没有完整 PWA 离线壳。Android 的程序在 APK 中，可独立离线启动。
- 当前支持 App 级串行任务队列，切换 App 内页面继续下载；刷新或关闭进程会中断未完成任务。不含断点续传、后台下载保活或跨域账号登录。每个下载操作最长120秒，失败可重试。

## 手机验收

1. 曲库 → 下载管理 → 试用原创示例源 → 下载到本地，观察真实进度、已保存状态和本地列表。
2. 进入学唱，确认音频实际播放；进入钢琴，确认8小节乐谱和发声键盘。
3. 保持本页已打开后断网，继续播放和选句；Android 可断网重开 App。网页刷新测试应保留联网来获取程序，但关闭素材服务后仍应从本地载入素材。
4. 更新同域网页或同签名 APK，确认下载记录、音频、歌词与谱子仍在。
5. 用错误校验值的测试目录、拒绝访问的地址和取消按钮确认有明确提示，原有资料不丢失。

核心测试覆盖目录验证、真实字节流计数、哈希、完整性、解析失败、取消与原资料保护。浏览器回归实际下载三类文件，重载页面并禁止所有远程素材请求，检查本地真实播放和谱面恢复。原生单测验证内容哈希、持久文件地址和路径限制；物理 Android16 离线启动与覆盖安装仍须手机验收。
