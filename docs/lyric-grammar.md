# 歌词语法解读

在歌词练习页长按某句，或选择该句后点击“解读本句”，进入语法解读。进入时暂停播放；在解读页可以单次播放这句真实音频，关闭后恢复进入前的练习片段、位置与循环设置，继续练习需要手动点播放。拖动歌词超过阈值会取消长按，以免滚动时误触。也提供按钮入口，方便无法长按的用户。

首次使用需在解读页填写兼容 OpenAI Chat Completions 的 HTTPS 完整接口地址、模型名和 API 密钥。默认展示 DeepSeek 的地址与模型名，也可以替换为其他兼容接口。提供商账户、密钥及费用由使用者自行管理；App 不内置或提供密钥。仅接口地址和模型名保存于本机，密钥仅保留在当前运行会话中，重启后须重新输入。不要把密钥提交到仓库或反馈报告。

点击开始后，所选单句发送至配置的提供商；追问时会附带本句解读和近期对话，不发送音频或整首歌词。发送前界面会显示提供商地址与隐私提示。语法结果和对话仅驻留页面，不作为练习记录保存。模型可能误解歌词、格式不符或无法访问；页面会显示错误并允许重试。浏览器版需要提供商支持跨域，Android 使用原生 HTTP；请求不跟随重定向。停止生成会取消界面等待，原生网络请求可能仍会在后台完成，但结果会被丢弃。

实现与测试不等于已经使用实际账户、实际手机验证；安装包、签名和公开版本以完整构建及发行检查结果为准。

词组卡片可切换假名显示。假名由模型随解读返回，只接受能够与原词组完整对应的片段；模型未提供或结构无效时保留原文，不自行猜测读音。模型读音可能不准确，请结合词典确认。追问和解读支持常见 Markdown，包括标题、粗体、列表、表格和代码；原始 HTML 不会执行。
