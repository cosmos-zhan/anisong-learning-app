原文件没有 tempo/sound/metronome 速度信息。界面明确提示暂用 ♩=100；按书写音符时值计算约 113.4 秒。该文件标注 Keyboard Part，没有展开式的完整录音时间轴。不能依据这个数字声称是完整 257.88 秒 MP3 的同步转录；本轮不补写小节、反复或臆测速度。原文件没有解析到反复/跳转。

用户可主动点击“练习此轨最高音（单音）”。每个同起点组只选择音高最高的原有事件，保留原音高、时值、休止、延音与小节 ID；谱面仍绘制完整原谱。持续显示“单音简化”提示，随时可返回原轨。它是键盘声部的最高音练习，不能声称就是人声旋律或完整左右手和弦演奏。谱面设置可选左手的同类练习。

仅当障碍为普通和弦/同轨重叠、且选择最高音后不再重叠时提供此选项。倚音、移调、微分音、未解决重叠等仍阻止，避免误播。原始轨道不会自动切换为简化轨道；刷新仅恢复用户已明确选过的模式。反馈记录 `practiceTrack: highest/original` 及实际谱表、声部。

## 手机操作

1. 同一 ChatGPT 账号打开 [钢琴试用页](https://anisong-learning-lab.woolly-mochi-2205.chatgpt.site/?song=haruhikage-crychic#piano)，刷新。首次自动载入原谱；已有本地谱优先恢复，可点“内置曲谱”重新载入本文件。
2. 横屏，确认显示 63 个小节按钮。原轨提示和弦；可先启用声音自由试琴。
3. 点“练习此轨最高音（单音）”，再点任一小节试听，或切“等待弹对”点“开始等待”。正确触键才推进，错键保留目标；休止点“下一步”。
4. 试多小节范围、0.75×、暂停、重练与刷新恢复。完整 MP3 / 歌词通过顶部“歌词学唱”进入；切模块会暂停旧音频，两套时间线独立。
5. 有问题用反馈报告，包含版本、模式、声部、范围和简化状态。请区分谱面本身缺段/无速度与播放器错误。

## 构建与恢复

将原上传恢复为忽略的 `private-media/haruhikage-crychic.musicxml`。私有 `.openai/private-media-sources.json` 的 `score` 项存放原上传恢复引用与校验值；不要把曲谱正文、临时下载 URL 或凭据写入公开 Git。`scripts/bundled-audio.mjs` 生成含内容哈希的 `.musicxml` 产物与 `bundled-audio.json.score` 配置。

后续私有发布须同时设置 `ANISONG_REQUIRE_BUNDLED_AUDIO=1`、`ANISONG_REQUIRE_BUNDLED_LYRICS=1`、`ANISONG_REQUIRE_BUNDLED_SCORE=1`，避免更新漏带任何素材。普通 GitHub 克隆与 CI 不带这些文件，仍支持导入与 CC0 示例。内置谱读取失败可重试或本地导入；不会回退成别首歌曲。手动导入与切歌曲通过令牌取消旧响应。
