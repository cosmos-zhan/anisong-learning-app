# 网易云分享链接导入

0.6.5-alpha.1 增加网易云短信 / 扫码登录、账号权限下载和上传台准备优化。入口：**曲库 → 下载管理 → 从网易云分享链接导入**。可粘贴歌曲 ID、完整歌曲链接、163cn.tv 短链接或完整分享文字。

1. 需要账号权限的歌曲先展开“登录网易云账号”：用短信验证码登录，或通过网易云 APP 扫码并确认；同一部手机可截图后从网易云扫一扫相册识别。
2. 点击“解析歌曲”，核对歌名、演唱者、音频格式与歌词数量；失败时展开“音频获取详情”查看具体阶段及状态码。
3. 点击“下载并导入本机”。下载实际音频后检查文件头、大小和实际时长，随后将音频和可用歌词一次性保存。
4. 完成后切到“已下载”，点击“歌词学唱”。保存成功后离线仍可读取，不需要再选本地文件。

原词、网易云提供的罗马音及翻译按原曲时间戳合并成 Anisong LRC；缺少、歧义或无法对齐的行会明确提示，不根据行号猜测，也不自动生成缺失译文或罗马音。无歌词的可获取曲目仍可保存音频。

这个入口只读取网易云并写入本机存储，**不上传到服务端，不修改在线目录，不包含管理凭据**。Android 使用 Capacitor 原生 HTTP，避免 WebView 的跨域限制；网页版隐藏该设备入口。

同一个网易云 ID 重复导入会更新一个本机条目，保留原有本机乐谱；本次没有获取到歌词时保留已有歌词。失败、取消或音频时长不符不会覆盖原有资料。下载与其他素材写入互斥。取消后忽略原生网络晚到的结果；原生 HTTP 底层请求受连接/读取超时约束，不宣称系统级后台下载或断点恢复。

Android 本机入口仅导入网易云实际返回且账号有权限取得的完整 MP3 / FLAC / M4A / AAC，保留原始格式与扩展名，单文件不超过 25 MiB。当前手机浏览器解码器不能读取实际时长时会拒绝保存；不导入或转换 NCM 等加密缓存。私人上传台 / 后台素材准备目前仍限 MP3。匿名可获取的歌曲无需登录；需要登录或会员 / 已购权限的歌曲按当前账号的实际结果判断。登录不会赋予额外歌曲权限，试听与时长不符的文件仍会拒绝。

## 发布到在线列表

所有者使用[私人上传台](https://anisong-upload-console.woolly-mochi-2205.chatgpt.site)：粘贴分享链接 → 解析 → “上传到在线曲库”。若上传台无法直接取得完整 MP3，会自动提交私人素材准备任务。后台通常每五分钟检查一次任务；排队可能因服务繁忙延迟。页面显示状态，完成后可检查音频与歌词并发布。后台准备本身不修改公开目录。页面最后上传文件并原子合并目录。完成后，其他 App 用户刷新在线列表即可下载。

相同网易云 ID 使用稳定的 `netease-<ID>`，重复发布更新对应条目并保留已有乐谱。上传台仅所有者可访问；在线素材服务沿用当前公开读取设置。普通 App 不具备这项发布权限。

## 后台素材准备

网易云在当前 Cloudflare 运行环境会对部分匿名请求返回空音频地址，而 GitHub 执行器已实测能够直接获取完整 MP3。上传台保留直接获取；必要时把歌曲 ID、标题和原曲时长交给受限后台任务。任务只访问网易云，限制完整 MP3 / 25 MiB，并用 ffprobe 检查时长、ffmpeg 全曲解码和 SHA-256 后存入私人暂存区。

GitHub 工作流通过短期 OIDC 身份访问任务服务，不需要新增个人访问令牌，也不持有素材管理密钥。服务仅接受固定仓库、指定工作流与受信分支，并检查签名、有效期和任务租约。MP3 和歌词正文不作为 Actions 产物或 Git 文件保存。

准备结果保留 24 小时，不对外公开。关闭页面不取消后台准备，可稍后重新解析同一链接复用结果。点击“上传到在线曲库”后才发布；同一歌曲保留稳定 ID 和已有乐谱。普通 Android App 不参与后台队列，也没有在线上传权限。

2026-10-26 后台验证：受限 GitHub 工作流 40212671648 已实际处理任务，返回 9,613,105 字节 MP3，240.300408 秒，全曲解码和 SHA-256 均通过；仅存放私人准备区，任务本身未发布目录。当前使用排队准备流程处理此前的 Cloudflare 直连限制。公开列表与 Android 来源上的两首歌曲一键下载、43 / 39 / 39 歌词及离线播放检查，以本次发行的真实 CI 为准。

## 0.6.5 登录与速度优化

- Android 登录状态由系统 Keystore 的 AES-GCM 密钥加密保存，HTTP 使用独立、无自动 Cookie 存储的客户端。原生桥日志关闭。账号凭据仅发往网易云主站，不随 CDN 音频请求或反馈报告发送；普通 APP 不上传在线曲库，也不把账号交给上传台。
- 私人上传台沿用所有者访问权限。站内登录以加密、HttpOnly、Secure、SameSite Cookie 保存，短信验证码只用于本次提交，不持久保存手机号或验证码。二维码与发短信操作均需主动点击。
- 必须使用后台准备时，上传台会把过滤后的网易云会话交给自己的素材服务，加密暂存至多 30 分钟；只有固定 GitHub 仓库与受信工作流的短期 OIDC 身份可在领取任务时读取。完成或失败后移除暂存凭据；不写入源码、Actions 环境变量、日志或产物。准备文件按账号隔离并仍保留 24 小时。
- 解析与下载共用两分钟的账号隔离缓存。上传台先检查已有准备结果；已就绪或正在进行的任务不重复探测。必要的直连接口并行尝试，四秒后转入兜底流程。
- 活跃执行器在处理真实任务后最多额外等候 90 秒，以两秒间隔接收同一轮后续歌曲；单轮工作有总时限。冷启动仍使用原有五分钟定时检查，调度繁忙时可能延迟，不能保证首次未缓存歌曲都即时完成。

《影色舞》分享链接已确认对应 ID `2097485072`、原曲约 209.453 秒、上游 fee=1。实际完整版获取需要在上述入口登录具有相应权限的账号；实现、模拟权限测试或二维码生成不代表该账号的真实完整版已经验证。最终真机和歌曲实测结果见本次 PR / 发行记录。


## 0.6.6 Android 登录修复

用户实测 0.6.5 在提交短信验证码后显示“网易云未返回完整登录状态”。原因是原生 HTTP 的登录 Cookie 又被装进浏览器 `Response`，WebView 按 Fetch 规则过滤 `Set-Cookie`，登录逻辑读不到 `MUSIC_U`。Node 的 Response 测试没有复现这个浏览器差异。

0.6.6 先从原生返回值提取且只保留 `MUSIC_U` / `__csrf`，在内存中关联到原响应，登录确认后仍写入 Keystore 加密存储。CDN 返回的 Cookie 不进入该通道；取消或登录失败不保存。短信与二维码确认共用修复，不把凭据放进响应头、localStorage、反馈或构建产物。新增 Chromium 检查复现旧版响应头被过滤，并验证实际客户端登录、保存和状态读取。

上传台真实短信登录已验证；用户确认同一账号在官方 APP 可完整播放《影色舞》。云端旧版 / v1 的新音频地址仍返回 403，官方外链未提供可用音频，浏览器直连也未通过；没有取得或发布该曲完整 MP3。该限制与这次 Android Cookie 丢失分别记录。修复后需在手机用同一账号重新登录并导入 ID `2097485072`，实际完整下载、时长检查与离线读取仍待真机确认。

## 0.6.7 下载接口、多格式与错误详情

手机已登录后仍显示“网易云当前没有提供可获取的完整 MP3”的实际代码问题包括：只接受 MP3、仅调用旧版播放接口、拿到第一个地址后取消其他候选，以及所有音频 HTTP 失败使用相同提示。该提示不证明会员权限不足；此前云端《影色舞》文件响应 403 也不能替代手机这次请求的状态码。

本机入口先用过滤后的账号会话请求 `/weapi/song/enhance/download/url/v1`，使用单个 `id` 和 `level=exhigh`；文件失败再检查播放 v1 / 兼容播放，以及无损与标准音质。接口参数参考 [API Enhanced 下载实现](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced/blob/main/module/song_download_url_v1.js) 与 [播放实现](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced/blob/main/module/song_url_v1.js)，只使用本项目既有 WeAPI 协议和网易云来源，不引入第三方解析服务。候选必须通过实际文件响应和文件头检查才可选中。较高音质超过大小限制时仍可选择通过检查的标准音质；实际保存前继续校验完整字节数与原曲时长。完整传输失败会移除已检查地址的缓存，重试重新取址。

“音频获取详情”只显示接口名称、音质、地址 / 文件阶段、HTTP 状态、上游数值返回码和格式；不显示短期签名地址、Cookie 或响应正文。HTTP 403 明确表示本次文件访问被拒绝，不据此判断 VIP 权限。网络异常不再误报为无法保存登录状态。

新增回归覆盖下载参数、真实文件响应后再选址、403 后其他合法接口可用、多种格式的 MIME / 扩展名、本机事务保存与重读、试听 / NCM / HTML 拒绝、失败缓存失效和诊断脱敏。浏览器检查使用自生成的两秒音频与原生 HTTP 替身，验证真实 Chromium 解码与 IndexedDB 保存；不包含私人歌曲或真实账号请求。《影色舞》约 209.453 秒完整版能否在用户手机网络完成下载、保存后离线读取，仍须实际手机结果确认；完整 App 与最终 APK 验证以本次发行附件为准。


## 0.6.8 当前客户端协议与完整歌曲验证

手机截图确认旧下载 / 播放路径返回了音频地址，但 MP3 文件请求是 HTTP 403；无损候选约 80.50 MiB，超过现有 25 MiB 限制。无来源头、普通 GET、服务商原 HTTP 地址及旧 EAPI 的 AAC / M4A 路径在云端对照中仍不能下载，不能把拒绝解释为用户没有 VIP。

当前客户端 XEAPI 流程使用服务商签名密钥注册和 X25519 请求封装，访问固定 `interface.music.163.com/api/bsr/sk/get` 与 `interface3.music.163.com/xeapi/song/enhance/player/url/v1`。会话仅发往后一个精确路径；注册只用本次随机设备 ID，CDN 无账号凭据。不使用第三方曲源、伪造出口 IP、反作弊令牌或 NCM 解密。WebCrypto 实现由上传台与 App 共用；原生普通 GET 的预检限制通过本地插件参数传递，不把该参数作为 HTTP 请求头发送。

2026-10-27 实际验证：同一登录账号已取得《影色舞》（2097485072）完整 MP3，8,380,845 字节，Chromium 全文件解码 209.453333 秒、44,100 Hz、双声道，SHA-256 `732bfef76aa41249c9adab2dbcaca550ebfccea1e73909a430442c5b915572dd`。原词 / 罗马音 / 翻译为 57 / 51 / 54 行。通过私人上传台真实发布后，在线列表为三首；原有两首保留，既有 App 可以直接刷新在线列表下载。25 MiB 文件限制不变，当前完整 MP3 约 8 MiB，不需要为了此曲下载 80.5 MiB 无损文件。

这些结果证明实际取址、完整文件与上传发布；物理 Android 16 的登录后本机导入仍需最终 APK 安装后确认。完整 App 门禁、离线下载以及最终 APK 版本与签名见本次 PR / Release 验证记录。
