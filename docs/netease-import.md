# 网易云分享链接导入

0.6.3-alpha.1 增加 Android 本机导入。入口：**曲库 → 下载管理 → 从网易云分享链接导入**。可粘贴歌曲 ID、完整歌曲链接、163cn.tv 短链接或完整分享文字。

1. 点击“解析歌曲”，核对歌名、演唱者、MP3 状态与歌词数量。
2. 点击“下载并导入本机”。下载实际 MP3 后检查文件头、大小和实际时长，随后将音频和可用歌词一次性保存。
3. 完成后切到“已下载”，点击“歌词学唱”。保存成功后离线仍可读取，不需要再选本地文件。

原词、网易云提供的罗马音及翻译按原曲时间戳合并成 Anisong LRC；缺少、歧义或无法对齐的行会明确提示，不根据行号猜测，也不自动生成缺失译文或罗马音。无歌词的可获取曲目仍可保存音频。

这个入口只读取网易云并写入本机存储，**不上传到服务端，不修改在线目录，不包含管理凭据**。Android 使用 Capacitor 原生 HTTP，避免 WebView 的跨域限制；网页版隐藏该设备入口。

同一个网易云 ID 重复导入会更新一个本机条目，保留原有本机乐谱；本次没有获取到歌词时保留已有歌词。失败、取消或音频时长不符不会覆盖原有资料。下载与其他素材写入互斥。取消后忽略原生网络晚到的结果；原生 HTTP 底层请求受连接/读取超时约束，不宣称系统级后台下载或断点恢复。

当前不接入网易云账号，不处理付费、VIP 或试听音频。支持匿名接口实际提供的完整 MP3，单文件不超过 25 MiB；没有获取到时显示原因，不能把所有曲目都标为可下载。

## 发布到在线列表

所有者使用[私人上传台](https://anisong-upload-console.woolly-mochi-2205.chatgpt.site)：粘贴分享链接 → 解析 → “上传到在线曲库”。页面会下载、检查音频与歌词，上传文件并原子合并目录。完成后，其他 App 用户刷新在线列表即可下载。

相同网易云 ID 使用稳定的 `netease-<ID>`，重复发布更新对应条目并保留已有乐谱。上传台仅所有者可访问；在线素材服务沿用当前公开读取设置。普通 App 不具备这项发布权限。

## 验证边界

新增回归检查链接、三类歌词、本机事务保存、重复导入、原谱保留、短音频拒绝、取消及原生 HTTP 适配。完整 App 构建和最终 APK 结果以当前 PR 的实际 CI 记录为准。云端测试不能代替 Android 16 真机安装、手机网络与离线重开验收。
