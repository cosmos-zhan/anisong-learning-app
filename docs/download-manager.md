# 下载管理（0.5.0）

主流程是App内 **在线歌曲 → 点击下载 → 下载任务 → 已下载 → 开始练习**。无需先用浏览器下载ZIP或手动解压。素材包仍作为“本地导入与存储”下的补充入口。

首页和曲库均有下载管理入口。页面分为三个标签：

| 页面 | 当前行为 |
| --- | --- |
| 在线歌曲 | 自动读取已配置素材源，显示歌曲、文件类型、总大小、已下载/更新状态；可搜索并点下载 |
| 下载任务 | App级单队列、真实字节进度、排队、取消、失败重试；切换App内页面继续下载 |
| 已下载 | 持久本地列表、素材大小、音频/歌词/乐谱状态；直接学唱/学谱，或移除下载副本 |

默认源为已部署的春日影目录，0.6.1 无需填写访问码，直接点击下载。App 打开下载页或刷新时读取在线目录，新增歌曲通常无需重新发 APK；操作见 [新增歌曲](adding-songs.md)。CC0 原创示例仍可切换使用，自定义源地址收进“下载源设置”。目录与媒体公开读取，管理员上传独立受保护；不会用私有站登录 Cookie 或客户端内置密钥替代下载服务。

## 下载与资料保留

`DownloadManager`位于 `packages/core/download-manager.ts`，由App持有生命周期，页面离开不取消任务。每首歌去重、顺序传输；成功前共享文件大小/SHA256/歌词/乐谱校验与一个IndexedDB事务，失败不替换旧版。下载完成通知根Workspace更新曲库；下载其他歌曲不会卸载正在练习的歌曲模块。

每个任务最长120秒，超时可重试；重试从头开始，不声称断点续传。任务和访问码只保存在当前运行内存中，不写入反馈、任务快照或磁盘；清理已结束任务会删除相应临时来源。刷新/关闭App会中断未完成任务，已下载素材和记录仍在IndexedDB。没有承诺浏览器后台、杀进程或锁屏后的下载保活，Android原生后台下载服务尚未接入。

移除下载在一个事务内删除该歌曲的canonical音频、LRC、乐谱和下载记录，保留歌曲及练习设置。确认界面明确保留已另存的谱库资料；原生播放器可能还保留音频缓存，不将列表显示的素材大小宣称为释放的整机磁盘空间。当前正在排队/下载的歌曲不能同时移除。重新下载可再次保存。

## 需要什么服务

最小服务不需要数据库、用户上传后台或音乐平台接口。一份目录和文件即可：

| 必需项 | 服务需要提供 |
| --- | --- |
| HTTPS文件托管 | MP3等音频、LRC、MusicXML/MXL的真实文件响应 |
| 歌曲目录 | `catalog.json`：歌曲ID/标题/版本、文件地址/大小/SHA256，格式见media-downloads.md |
| 跨域 | 允许实际网页Origin和Android的 `https://localhost`，支持GET及鉴权预检 |
| 私人访问控制 | 素材源专用访问码或短期签名地址，保护目录和每个文件；平台API密钥只能在服务端使用 |

当前默认服务采用独立 Site 与私有 R2 存储，通过服务端接口公开提供已授权文件。管理员先上传文件，再发布保留已有歌曲的完整目录；详见 [当前服务与可选模板](private-media-service.md)。同仓库 `services/media-source` 保留受限 Worker / Node 静态模板，可用于其他自定义私人源，与当前默认服务不同。

## 手机验收

1. 公开 App 打开曲库→下载管理，等待默认春日影在线列表，直接点“下载到本地”，不填写访问码。
2. 查看下载任务的字节数；切回曲库，再回下载管理检查完成状态。
3. 已下载中直接进入歌词学唱或钢琴学谱，验证真实声音；断网重开App检查本地恢复。
4. 配置包含多首歌的目录，连续加入任务，确认排队、取消及失败重试；失败后原有资料仍可用。
5. 移除下载前可选保留；确认移除后下载列表更新，歌曲和练习设置保留。
6. 默认春日影已接入独立公开读取服务；每次新增歌曲仍需验证在线下载、离线读取和真实播放，不能用原创示例或已有春日影的通过记录代替。

自动化覆盖队列去重/顺序/进度、活动与排队取消、重试授权不泄露、超时后续任务、页面卸载不中止、事务移除与资料保留。真实Chromium在393×873、740×320延迟实际音频响应，离开下载页后放行网络，确认曲库收到完成记录；同时检查认证、完整性、离线导入、重载后的真实媒体时钟推进、谱面恢复和移除操作。完整App门槛仍包含所有前端/发布/原生测试与APK装配，物理Android16后台及覆盖安装仍须实测。
