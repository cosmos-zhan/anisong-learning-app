# 学唱 R2：译文、罗马音与跟随滚动（0.3.9）

本轮根据已确认的 R2 交互稿实现，不改变真实音频播放引擎和原曲时间坐标。

- 原文下方显示罗马音、中文译文，默认开启；右上「显示」可分别关闭。偏好保存在此设备，缺少学习文本时开关禁用并明确提示。打开显示面板不中断播放、不改变范围；关闭后跟随当前真实句。
- 自动滚动独立开关，默认开启。当前句由实际播放器 position 决定，包括暂停、变速、seek 与循环返回；没有增加模拟计时器。
- 手指滑动、滚轮、键盘滚动或拖动滚动条暂停跟随，显示「回到当前句」。选取多句起点后暂缓跟随，确定终点后恢复；自动滚动关闭时不主动改变列表位置。
- 固定顶栏与播放器，歌词独立滚动。竖屏上下布局，短横屏歌词在左、播放器在右。ResizeObserver 在尺寸变化时重新定位当前句。
- 反馈诊断附带三项显示偏好，不包含原文、译文、罗马音、音频或文件路径。

## 学习文本输入

保留原 LRC 的每句原文和时间戳，添加同时间戳的明确标记行：

```lrc
[00:16.300]いつまでも覚えていたい
[00:16.300][romaji]Itsumademo oboete itai
[00:16.300][translation]想要一直记住
```

标记不区分大小写；支持多时间戳和 offset；学习文本不形成新的循环句，也不改变结束边界。普通重复时间戳继续按旧规则合并，不猜测语言。没有对应原文的学习文本会被忽略并告警。此扩展不是通用 LRC 标准；普通原文 LRC 仍可正常使用。

公开示例附一行可切换的学习文本。私人春日影学习文本来自所有者先前的 42 句学习卡，与原 LRC 对齐后用于私有测试页；不得提交公共 Git 或公共 APK。

## 手机验收

1. 进入学唱，点「显示」，分别关闭/开启两项；重新进入页面应保留偏好，原文始终可见。
2. 选择较多歌词，实际播放，当前句随音频推进；循环末尾回到开头，页面也跟回。
3. 手动上下滑动，确认不会被强制拉回；点「回到当前句」恢复。
4. 关闭自动滚动后继续播放；列表应保持手动位置，当前高亮仍随真实进度变化。
5. 多句选起点后可自由浏览尾句，确定范围后从起点播放；片段微调与变速仍按原逻辑生效。
6. 横竖屏切换，检查当前句和播放控制；特别检查长句及系统大字体。
