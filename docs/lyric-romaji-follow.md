# 歌词注音与跟随

学唱页和显示设置预览将罗马音放在原文上方。原文与罗马音仍取自同一条 LRC 原有数据，不改变时间戳或存储格式。使用本机日文分词及假名读音、原有罗马音的空格进行分组；日文词组与注音作为一个整体换行。汉字读音来自原有歌词中的罗马音，自动分组无法证明来源读音正确。罗马音按音节而非词组密集分隔、无法可靠匹配、文本过长或环境缺少日文分词时，不猜测逐词位置，而在原文上方显示“整句注音”。罗马音开关关闭时只显示原文，中文翻译保持独立开关。

切句时自动滚动使用浏览器平滑滚动。手动浏览会暂停跟随并停止尚未完成的自动滚动；点击“回到当前句”或选句可恢复。系统启用减少动态效果时使用即时滚动。尺寸变化只在实际发生时重新定位，避免尺寸监听器取消切句动画。

本地用用户已有的春日影原词和罗马音检查了 42 行的分组，未将私人歌词写入仓库。自动化使用原创测试句覆盖对齐、回退、长音、开关、手动打断、尺寸变化及减少动态效果；并增加手机和横屏浏览器几何与实际动画帧测试。自动分组可能因为日文分词或歌词提供方的注音习惯产生错误，尚需人工核对其他歌曲；Android 16 真机键盘与实际滚动表现仍需验收。
