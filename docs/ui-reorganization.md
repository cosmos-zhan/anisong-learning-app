# 页面整理与验收

本次按 UI 设计稿整理下载与导入、歌曲资料、语法解读及应用更新。首页、曲库、设置保留底部主导航；其他页面使用顶部返回，避免操作区被导航挤压。

- 下载与导入：独立入口、在线歌曲、下载任务、已下载、下载源设置及本地文件导入；Android 另有网易云分享链接及账号页面。下载任务切换页面后继续，关闭应用或刷新后需重新下载。
- 歌曲资料：音频、歌词及乐谱操作分组；素材包导入仍有独立入口，导入后保存至本机。
- 语法：本句解读、按句追问、模型及歌词上下文设置分开；返回设置前保留未发送的问题，历史按歌曲及句子存储。歌词、歌名和对话会按所选范围发送给所配置的模型服务商。
- 设置：应用更新说明单独成页。数据仍由原有本地存储管理，UI 调整不会清除已保存的内容。

## Android 16 与真实服务验收

1. 从下载入口进入在线歌曲、任务和已下载，切页和系统返回后确认任务状态与本地内容；分别测试素材包导入失败、成功和移除。
2. 在真机登录或退出网易云，返回分享链接页确认输入仍在；尝试实际解析与下载，检查失败和取消提示。
3. 打开语法解读，切换追问与上下文设置，输入中文并打开/关闭键盘，确认发送框与系统导航栏不遮挡、滚动正常；系统返回后草稿和历史符合预期。
4. 使用自己的模型服务实际完成一次解读和追问，并检查超时、错误、停止生成和恢复；重开同一句及另一首歌，确认历史隔离。
5. 在 320dp 左右宽度及横屏检查顶部返回、长文字、三个主导航页和歌曲资料文件选择器；覆盖安装后确认本地歌曲及练习记录可读。

自动化检查不能替代上述真机键盘、Android WebView 存储和第三方服务验收。
